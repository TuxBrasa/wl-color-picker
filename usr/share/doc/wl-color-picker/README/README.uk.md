wl-color-picker

Простий вибір кольору для Wayland і wlroots, який використовує
grim та slurp.

wl-color-picker дає змогу вибрати колір безпосередньо з екрана,
відредагувати його, скопіювати до буфера обміну та зберегти для
подальшого використання.

Можливості

Вибір кольорів з екрана за допомогою slurp і grim.

Редагування вибраного кольору за допомогою YAD.

Безпосереднє копіювання кольорів до буфера обміну.

Збереження кольорів для подальшого використання.

Перегляд і редагування збережених кольорів.

Видалення окремих збережених кольорів.

Видалення всіх збережених кольорів.

Запобігання збереженню дублікатів кольорів.

Використання ImageMagick або GraphicsMagick для отримання кольору пікселя.

Відображення системних сповіщень під час копіювання кольору.

Можливість вимкнути сповіщення.

Графічне меню, якщо команду не вказано.

Довідка з командного рядка.

Перевірка сеансу Wayland.

Інтернаціоналізація за допомогою gettext.

Підтримка кількох мов.

Використання
Графічний вибір кольору
wl-color-picker


Виберіть позицію на екрані. Вибраний колір відкриється в редакторі
кольорів, де його можна налаштувати перед копіюванням до буфера обміну
та збереженням.

Режим буфера обміну
wl-color-picker clipboard


Вибраний колір безпосередньо копіюється як шістнадцяткове RGB-значення:

#FF5733

Збережені кольори
wl-color-picker saved


У вікні збережених кольорів можна:

відкрити та відредагувати збережений колір;

скопіювати вибраний колір до буфера обміну;

зберегти відредагований колір;

видалити збережений колір;

видалити всі збережені кольори.

Збережені кольори зберігаються в:

~/.config/wl-color-picker/colors


Якщо доступна змінна $XDG_CONFIG_HOME, вона має пріоритет.

Параметри
--no-notify

Вимикає системне сповіщення після копіювання кольору:

wl-color-picker clipboard --no-notify

--help
wl-color-picker --help


Також підтримуються:

wl-color-picker -h
wl-color-picker help
wl-color-picker ?

Команди
Команда	Опис
wl-color-picker	Відкрити графічний вибір кольору
wl-color-picker clipboard	Вибрати колір і безпосередньо скопіювати його до буфера обміну
wl-color-picker saved	Показати збережені кольори
wl-color-picker --help	Показати довідку
Залежності

slurp — надає засіб вибору позиції на екрані.

grim — захоплює вибрану область.

YAD — надає редактор кольорів і графічний інтерфейс.

wl-clipboard — надає wl-copy.

libnotify — надає notify-send.

gettext — забезпечує інтернаціоналізацію.

ImageMagick або GraphicsMagick — перетворює захоплений піксель на шістнадцяткове значення кольору.

Інтернаціоналізація

wl-color-picker використовує GNU gettext для перекладів.

Доступні мови:

Німецька (de)

Іспанська (es)

Французька (fr)

Італійська (it)

Японська (ja)

Португальська (pt)

Бразильська португальська (pt_BR)

Російська (ru)

Українська (uk)

Китайська (zh)

Файли перекладів знаходяться в:

/usr/share/doc/wl-color-picker/po/


Скомпільовані переклади встановлюються в:

/usr/share/locale/


Щоб перевірити певну мову:

LANG=es_ES.UTF-8 wl-color-picker

Переклад

Шаблон gettext знаходиться в:

/usr/share/doc/wl-color-picker/po/wl-color-picker.pot

Створення перекладу
msginit \
    --locale=uk \
    --input=po/wl-color-picker.pot \
    --output=po/uk.po

Оновлення перекладу
msgmerge \
    --update \
    po/uk.po \
    po/wl-color-picker.pot

Компіляція перекладу
msgfmt \
    po/uk.po \
    -o /usr/share/locale/uk/LC_MESSAGES/wl-color-picker.mo

Налаштування

Збережені кольори зберігаються в:

${XDG_CONFIG_HOME:-$HOME/.config}/wl-color-picker/colors
