wl-color-picker

Простой выбор цвета для Wayland и wlroots с использованием
grim и slurp.

wl-color-picker позволяет выбрать цвет непосредственно с экрана,
отредактировать его, скопировать в буфер обмена и сохранить для
дальнейшего использования.

Возможности

Выбор цвета с экрана с помощью slurp и grim.

Редактирование выбранного цвета с помощью YAD.

Копирование цвета непосредственно в буфер обмена.

Сохранение цветов для дальнейшего использования.

Просмотр и редактирование сохранённых цветов.

Удаление отдельных сохранённых цветов.

Удаление всех сохранённых цветов.

Защита от сохранения дубликатов цветов.

Использование ImageMagick или GraphicsMagick для получения цвета пикселя.

Отображение системных уведомлений при копировании цвета.

Возможность отключить уведомления.

Графическое меню, если команда не указана.

Справка из командной строки.

Проверка сеанса Wayland.

Интернационализация с помощью gettext.

Поддержка нескольких языков.

Использование
Графический выбор цвета
wl-color-picker


Выберите позицию на экране. Выбранный цвет откроется в редакторе
цветов, где его можно настроить перед копированием в буфер обмена
и сохранением.

Режим буфера обмена
wl-color-picker clipboard


Выбранный цвет напрямую копируется в виде шестнадцатеричного
RGB-значения:

#FF5733

Сохранённые цвета
wl-color-picker saved


В окне сохранённых цветов можно:

открыть и отредактировать сохранённый цвет;

скопировать выбранный цвет в буфер обмена;

сохранить отредактированный цвет;

удалить сохранённый цвет;

удалить все сохранённые цвета.

Сохранённые цвета хранятся в:

~/.config/wl-color-picker/colors


При наличии переменной $XDG_CONFIG_HOME используется указанный
в ней каталог.

Параметры
--no-notify

Отключает системное уведомление после копирования цвета:

wl-color-picker clipboard --no-notify

--help
wl-color-picker --help


Также поддерживаются:

wl-color-picker -h
wl-color-picker help
wl-color-picker ?

Команды
Команда	Описание
wl-color-picker	Открыть графический выбор цвета
wl-color-picker clipboard	Выбрать цвет и напрямую скопировать его в буфер обмена
wl-color-picker saved	Показать сохранённые цвета
wl-color-picker --help	Показать справку
Зависимости

slurp — предоставляет выбор позиции на экране.

grim — захватывает выбранную область.

YAD — предоставляет редактор цветов и графический интерфейс.

wl-clipboard — предоставляет wl-copy.

libnotify — предоставляет notify-send.

gettext — обеспечивает интернационализацию.

ImageMagick или GraphicsMagick — преобразует захваченный пиксель в шестнадцатеричное значение цвета.

Интернационализация

wl-color-picker использует GNU gettext для переводов.

Файлы переводов находятся в:

/usr/share/doc/wl-color-picker/po/


Скомпилированные переводы устанавливаются в:

/usr/share/locale/


Чтобы проверить язык:

LANG=es_ES.UTF-8 wl-color-picker

Перевод

Шаблон gettext находится в:

/usr/share/doc/wl-color-picker/po/wl-color-picker.pot

Создание перевода
msginit \
    --locale=uk \
    --input=po/wl-color-picker.pot \
    --output=po/uk.po

Обновление перевода
msgmerge \
    --update \
    po/uk.po \
    po/wl-color-picker.pot

Компиляция перевода
msgfmt \
    po/uk.po \
    -o /usr/share/locale/uk/LC_MESSAGES/wl-color-picker.mo

Настройка

Сохранённые цвета хранятся в:

${XDG_CONFIG_HOME:-$HOME/.config}/wl-color-picker/colors
